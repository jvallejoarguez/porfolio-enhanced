# Javier Vallejo logo options

Three SVG directions prepared on 22 September 2026. Option 2, Cut, was selected for the portfolio. The production assets are `public/logo.svg` and `public/favicon.svg`; this folder preserves the comparison.

1. **Connected** — one rounded stroke joins J and V. The favicon uses a slightly heavier stroke for small sizes.
2. **Cut** — a solid JV ligature with a shared top edge. Recommended for its clear silhouette at small sizes.
3. **Lowercase** — a rounded j and geometric v, for a more informal identity.

Each direction includes a standalone SVG mark and a matching blue-and-white SVG favicon. The paths are self-contained and require no fonts or external assets. The wordmarks in the comparison use the portfolio's existing Geist font.

Open `index.html` through the project's Vite development server at `/design/logo-options-2026-09-22/`. Switch between blue and monochrome or try each mark in the header. Downloads are available beneath each option.

`logo-options.png` is the full comparison; `overview.png` is the compact comparison. Checked on desktop and mobile, including favicon samples at 16 and 32 CSS pixels on light and dark backgrounds.
